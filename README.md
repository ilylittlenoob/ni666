# CPU LAB 微處理機互動實驗室

以單一 HTML 檔案實作，無需安裝依賴。下載並用瀏覽器開啟 `index.html` 即可操作。

## 模組

- **MOV 組譯實驗**：把支援的 `MOV AX, ...` 指令轉成 8086 機器碼，觀察定址與資料傳送。
- **定址法實驗**：七種定址模式、可編輯的十六進位記憶體、EA 與運算元追蹤。
- **CPU 指令週期**：取指令、解碼、ALU 運算與寫回；EU／BIU 風格的霓虹方塊圖。
- **通訊方向**：單工、半雙工、全雙工的逐位元傳輸模型。
- **USB NRZI**：低速／全速資料片段的編解碼、波形、六個連續 1 後填充 0 與錯誤檢查。
- **機器碼實驗台**：輸入 HEX bytes、指定載入位址與 I/O 埠、逐步執行並控制四位七段顯示器。

## 機器碼實驗台

支援 8086 指令子集合：MOV、ADD、SUB、無號 MUL／DIV、AND、OR、XOR、NOT、NEG、INC、DEC、CMP、TEST、JMP、短程條件跳躍、LOOP、OUT、NOP、HLT。算術與邏輯運算使用暫存器或立即值；各指令的支援編碼列於網頁內。

畫面顯示 CF、ZF、SF、OF、PF、AF，`—` 表示該指令未定義的旗標。除以零、商溢位、未配置的 I/O 埠與越界跳躍會停止執行。

預設程式起點為 `0000:0100h`，`80h` 埠選擇左起第 0～3 位，`81h` 埠寫入段碼。段碼 bit7～bit0 為 `dp g f e d c b a`，1 表示點亮。這是教學用的 I/O 配置，可在畫面修改。

按「加法＋CMP 分支顯示」可觀察 3 + 5、CMP 與 JNE 如何讓七段顯示器顯示 8 或 E；另有乘除、邏輯、迴圈及顯示 1234 的範例。

各模組為獨立教學模型，並非完整的 8086 或 USB 硬體模擬器。原定址模組採 8-bit 數值與 8 個位址；機器碼實驗台提供 16-bit 暫存器與 64 KiB 程式位址空間，單次載入最多 512 bytes。
